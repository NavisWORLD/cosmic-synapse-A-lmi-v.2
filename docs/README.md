## Source-of-truth order

For current engineering status, prefer:

1. CI status on the exact current `main` SHA;
2. root README / Quick Start / Testing / System Ready status;
3. `PRODUCT_WORKFLOW.md` and `FINAL_CLOSURE_EVIDENCE.md`;
4. active architecture/provenance/claims/security/reproducibility docs;
5. subproject active READMEs;
6. preserved historical material for context only.

A historical filename, experiment, paper, or demo is evidence of project lineage, not automatic evidence that every claim inside it is currently verified.
